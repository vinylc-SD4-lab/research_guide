    공간 예약

    ※ 두 공간에서 동시에 진행되므로, 한 공간만 예약할 경우 다른 직원의 사용 일정과 겹칠 수 있습니다.

조사실 - 영상·오디오 연결

카메라를 HDMI 익스펜더에 연결한 뒤, 각 포트와 4층 사용자 관찰실의 송출 화면이 올바르게 연결되었는지 확인합니다.

  1. 1
    배치도(PAGE 7~8) 기준으로 카메라와 삼각대를 배치합니다.
  2. 2
    각 카메라에 전원을 연결하고 정상적으로 켜졌는지 확인합니다.
  3. 3
    각 카메라를 송출용 HDMI 익스펜더 1~4번 포트에 연결합니다.
  4. 4
    익스펜더 상단의 표시등을 확인합니다.
    → 표시등에 초록불이 모두 점등되면 정상적으로 연결된 상태입니다.
  5. 5
    모든 연결이 완료되면 배선을 정리하고, 참여자의 이동 동선을 방해하지 않는지 확인합니다.
    • HDMI·전원 케이블 등 노출되는 선은 가능한 한 안보이게 정리합니다.
    • 노출되는 내부 장비와 배선은 가림막 등을 통해 가려 조사실 전면이 정돈된 상태로 보이도록 합니다.

카메라 설치

  • 최대한 높게 설치
    촬영 영역을 넓게 확보하고, 참여자의 손이나 팔에 시료가 가려지는 상황을 줄일 수 있습니다.
  • 테이블 가장자리 쪽에 설치
    스탠드가 참여자의 시야와 동선을 방해하지 않도록 하고, 참여자가 스탠드에 부딪혀 화각이 변경되는 것을 방지합니다.

촬영 영역 표시

  • 스탠드 설치를 완료하고 위치를 고정합니다.
    → 높이나 위치가 바뀌면 촬영 영역도 달라지므로 반드시 먼저 완료합니다.
  • 탑뷰 카메라 화면을 켜고 실제 화각을 확인하며, 촬영 영역 가이드를 배치합니다.
  • 가이드의 바깥선을 따라 마스킹 테이프를 부착합니다.
  • 표시한 촬영 영역이 화각 안에 충분히 들어오는지 확인합니다.

조사실 - 무선 마이크

송출용 무선 마이크와 녹화용 핀마이크는 서로 다른 연결 경로를 사용하므로, 각각의 연결과 작동 상태를 확인합니다.

※ 추가 확인 필요 — 유선 마이크: FGI 등 조사 유형에 따라 유선 마이크를 사용할 수 있으므로, 실제 사용 여부와 연결 경로를 확인한 뒤 본 가이드에 추가합니다. 사용이 확정될 경우 마이크별 설치 위치와 수음 범위, 믹서 연결 채널까지 함께 표준화합니다.

  1. 1
    마이크 믹서 전원 및 작동 상태를 확인합니다.
  2. 2
    KANALS 무선 마이크 수신기 전원을 켭니다.
  3. 3
    KANALS 무선 마이크 송신기 전원을 켜고 수신기와의 연결 상태를 확인합니다.
  4. 4
    DJI Mic Mini 수신기(RX)를 캠코더의 3.5mm 마이크 단자에 연결합니다.
    → 캠코더에서 외부 마이크가 정상적으로 인식되는지 확인합니다.
  5. 5
    DJI Mic Mini 송신기(TX)의 페어링 상태를 확인합니다.
    • 완료 신호: 수신기(RX)의 표시등이 모두 초록색으로 점등되면 정상적으로 페어링된 상태입니다.
    • 연결 문제 발생 시: 송신기와 수신기를 DJI 충전 케이스에 넣었다가 다시 꺼낸 후 연결 상태를 확인합니다.
    • 다이얼 설정 참고: 수신기 다이얼을 + 방향으로 돌릴수록 주변 소리까지 함께 수음되며, - 방향으로 돌릴수록 마이크 중심으로 수음 범위가 좁아집니다. 일반적인 조사 환경에서는 0(중앙) 위치를 권장합니다.

마이크 착용 및 음향 확인

마이크의 위치와 방향이 조금만 달라져도 음량과 수음 품질이 크게 달라질 수 있으므로, 착용 후 반드시
실제 송출 음향까지 확인합니다.

※ 착용 원칙: 송출용 무선 마이크(KANALS)는 수음 방향과 위치에 따라 4층으로 전달되는 음향 품질이 크게 달라질 수 있습니다. 따라서 참여자가 직접 착용하기보다 '장비 담당자'가 위치와 방향을 확인하며 착용을 안내합니다.

착용 시 체크 포인트

  • 마이크 헤드가 입 방향을 향하는가 (아래·옆·바깥 향하지 않는가)
  • 옷깃·머플러·머리카락·명찰 등에 수음부가 가려지지 않는가
  • 착용 높이·거리가 참여자마다 크게 다르지 않은가 (세션 간 음량 편차 방지)
  • 4층 스피커를 통해 관찰실에서 음성이 실제로 명확하게 들리는가

    • 2.설정 > 기본설정에서 아래 항목을 활성화합니다.
      • 대화 자동 감지
      • 실시간 기록 표시
      • 음성 파일 로컬 저장
    • 3.Tiro가 실행된 맥북을 HDMI 4번 포트에 연결합니다.

    • 2.번역 기능이 활성화되어 있는지 확인합니다.
    • 3.참관자가 번역 내용을 쉽게 확인할 수 있도록 컨퍼런스 모드를 활성화합니다.

스크립트 정리 방법

촬영이 끝난 영상에서 음성을 추출하고, 이를 텍스트 스크립트로 변환하는 절차를 안내합니다.

  1. 1
    영상 파일 추출
    • 1.카메라의 SD카드를 PC에 연결해 영상 파일을 확인합니다.
      • 시료 카메라 영상은 AVCHD 규격으로 저장되어 있어, 일반 폴더처럼 바로 영상 파일이 보이지 않을 수 있습니다.
      • 보이지 않을 경우, SD카드에서 AVCHD 폴더 펼쳐보기를 선택 > BDMV 폴더 펼쳐보기를 선택 > STREAM 폴더 안에서 실제 영상 파일을 확인하고 복사합니다.
  2. 2
    음성 파일 추출 (Mac 기준)
    • 1.추출한 영상 파일을 QuickTime Player로 엽니다.
      Mac이 아닌 Windows의 경우, 반디컷(Bandicut)을 이용하면 음성 파일 추출이 가능합니다.
    • 2.상단 메뉴에서 파일 > 다음으로 내보내기 > 오디오 전용을 선택합니다.
    • 3.영상에서 음성만 분리된 파일이 저장됩니다.
  3. 3
    스크립트(STT) 변환
    • 1.추출한 음성 파일을 Tiro에 업로드해 텍스트 스크립트로 변환합니다.
      → 핀마이크 없는 조건에서 자체 비교한 결과 Tiro(오류율 5.96%)가 클로바노트(오류율 8.98%)보다 인식 정확도가 더 높게 나와, 스크립트 변환 도구로 Tiro를 사용합니다. [STT_정확도평가 참조]
    • 2.변환된 스크립트를 검토하고 필요한 부분을 보정합니다.

참여자 대기 장소·동선

이슈 참여자 대기 장소는 우선 B1층으로 계획하고 있으나, 실제 동선과 대기 환경은 다음 실사에서 확인이 필요합니다.

배경

참여자 대기 장소는 현재 B1층으로 계획하고 있지만, 가이드 문서에 별도로 정리된 내용은 없어 실제 동선(건물 진입부터 대기 장소까지)과 대기 환경(공간·안내 방식)은 아직 실사로 검증이 필요합니다.

다음 실사를 통해 하기 항목 확인

  • B1층 대기 장소까지의 실제 동선 및 대기 환경
  • 참여자 안내 방식 (동선 안내, 표지판 등)

STT Raw data 정제 및 Matrix Table 작성

이슈 지금까지는 Raw data를 분석용 Matrix Table로 정리하는 작업을 수작업으로 진행해, 상당한 리소스가 소요되고 있습니다.

배경

지금까지는 스크립트 변환 후 실제 분석에 들어가기 전, Raw data를 Matrix Table(엑셀 정리) 형태로 만드는 과정을 담당자가 직접 수작업으로 진행해왔습니다. 이 과정에서 상당한 시간과 리소스가 소요되어 효율화가 필요하며, 효율화 이후 실제 분석을 진행하는 과정에서 필요한 스킬·진행 방법도 함께 고려되어야 합니다.

Matrix Table 정제 효율화 방안 검토를 통해 하기 항목 확인

  • 자동 정제·분류 등 업무 효율화에 활용 가능한 AI 도구·방식
  • 적용 시 예상되는 리소스 절감 효과
  • 효율화 이후 실제 분석 진행에 필요한 스킬 및 진행 방법
